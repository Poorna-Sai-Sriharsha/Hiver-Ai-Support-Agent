# REMEDIATION PLAN: Hiver AI Support Agent

This plan outlines the systematic fixes required to transform the current "prototype facade" into a technically defensible, scientifically honest production-grade AI support agent.

## Core Principle: Scientific Honesty > High Metrics
**Every claim must be backed by a verifiable artifact. Truthful lower metrics are preferred over fabricated high metrics.**

---

## Remediation Matrix

| Issue | Root Cause | Fix | Validation Method | Expected Artifact | Status |
|---|---|---|---|---|---|
| **Golden Set Fraud** | Labels were synthetically generated by an LLM, not humans. | Implement a real human-annotation workflow via Streamlit. Sample 200 real AmazonHelp conversations. | Audit labels against source tweets; verify timestamped annotation logs. | `evaluation/golden_set.csv`, `evaluation/GOLDEN_SET_PROVENANCE.csv` | PENDING |
| **Intent Metric Fabrication** | Mock mappings and synthetic labels inflated the Macro-F1 to 0.91. | Remove all mock/hardcoded mappings. Re-evaluate using the new human golden set. | Compare `metrics.json` with actual labels in the human golden set. | `artifacts/final_metrics.json` | PENDING |
| **Inconsistent Taxonomy** | No single source of truth for intents; code/docs/labels diverge. | Centralize taxonomy in `config/intents.yaml`. Generate all other references from this file. | Automated schema validation script. | `config/intents.yaml`, `INTENTS.md` | PENDING |
| **Naive Grounding** | Grounding score is simple keyword overlap, not factual support. | Implement a "Claim-Support" pipeline: Extract claims $\rightarrow$ Compare to evidence $\rightarrow$ Classify support level. | Manual audit of 50 grounded responses vs retrieved evidence. | `artifacts/GROUNDING_AUDIT.md` | PENDING |
| **Misleading Escalation** | Escalation reasons are generic LLM output, not tied to real signals. | Rebuild as an explicit policy: Signal $\rightarrow$ Decision $\rightarrow$ Reason. (e.g., Retrieval score < 0.3 $\rightarrow$ Escalate). | Traceability check: Ensure reason matches the triggered signal. | `artifacts/ESCALATION_RISK_REPORT.md` | PENDING |
| **Mocked LLM Judge** | The evaluator used mock scores instead of real LLM calls. | Integrate real API calls (Anthropic/OpenAI) into the evaluation loop. | Verify API logs/costs correlate with evaluation runs. | `artifacts/judge_scores.json` | PENDING |
| **Missing Human Validation** | Claimed human-judge agreement without actual human data. | Create a human-review interface in Streamlit. Score 40-60 samples. Compare to LLM judge. | Calculate Cohen's Kappa / Correlation between human and LLM. | `evaluation/judge_validation.csv`, `evaluation/JUDGE_VALIDATION.md` | PENDING |
| **API Fragility** | Cloud API calls lack error handling, causing system crashes. | Implement bounded retries, exponential backoff, and safe fallbacks for all `LLMClient` methods. | "Chaos testing" (simulated timeouts/429s/500s). | `artifacts/API_RESILIENCE_REPORT.md` | PENDING |
| **OOM Risks** | Full dataset processing loads too much into memory. | Refactor `preprocessing` to use chunking/streaming for the 3M-row dataset. | Memory profiling during full-dataset run. | `artifacts/PERFORMANCE_REPORT.md` | PENDING |
| **Insufficient Testing** | Core logic lacks unit/integration tests; rely on "happy path". | Build comprehensive test suite (`tests/`) targeting boundary cases, typos, and adversarial inputs. | Pytest coverage report (Target: 80%+ core logic). | `tests/` directory, `coverage.json` | PENDING |
| **Retrieval Leakage** | No automated guarantee that test data is absent from index. | Add assertions in `VectorStore` and `evaluation` to block IDs present in the golden set. | Run a "collision check" script across all splits. | `artifacts/FINAL_LEAKAGE_AUDIT.md` | PENDING |
| **Hardcoded UI** | `app.py` displays static strings instead of real metrics. | Connect Streamlit metrics to `artifacts/metrics.json` and the live agent pipeline. | Verify UI numbers change when the underlying model/data changes. | `app.py` (updated) | PENDING |

## Execution Sequence

1.  **Foundation**: `config/intents.yaml` $\rightarrow$ `INTENTS.md` $\rightarrow$ Taxonony Validation.
2.  **Data**: Human Golden Set Annotation $\rightarrow$ Provenance $\rightarrow$ Leakage Audit.
3.  **Backend**: API Resilience $\rightarrow$ Memory Safety $\rightarrow$ Real Intent Classifier.
4.  **Logic**: Grounding Rebuild $\rightarrow$ Escalation Policy $\rightarrow$ Retrieval Assertions.
5.  **Evaluation**: Real LLM Judge $\rightarrow$ Human Judge Validation $\rightarrow$ Final Metrics.
6.  **UI/Docs**: Streamlit Update $\rightarrow$ Final Report $\rightarrow$ Interview Readiness.
7.  **QA**: Full Test Suite $\rightarrow$ Final End-to-End run.
