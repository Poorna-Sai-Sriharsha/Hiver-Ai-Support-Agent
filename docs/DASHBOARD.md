# Internal Operations Dashboard Documentation

The Streamlit application (`app.py`) serves as the internal evaluation and operations interface for the Hiver AI Support Agent. It is designed for engineers and annotators, not as a customer-facing product.

## Page-by-Page Specification

### 1. Overview
**Purpose**: Provides a high-level snapshot of the system's health and dataset statistics.
-   **Inputs**: `artifacts/metrics.json`, `data_profile.json`.
-   **Metrics**: Headline Macro-F1, Golden Set size, and raw dataset row counts.
-   **Interaction**: Read-only.

### 2. Live Support Agent
**Purpose**: Allows engineers to test the end-to-end pipeline in real-time.
-   **Inputs**: Customer message, optional conversation context.
-   **Outputs**:
    -   **Intent Prediction**: Predicted category and confidence score.
    -   **Escalation Decision**: Final decision (AUTO-HANDLE/ESCALATED) and the reasoning behind it.
    -   **Draft Reply**: The grounded response generated by the agent.
    -   **Evidence Trace**: The top-3 historical resolutions used to generate the reply.
-   **Interaction**: "Process Message" button triggers the full `SupportAgent.process_message()` pipeline.

### 3. Evaluation Dashboard
**Purpose**: Visualizes the performance of the AI Agent against baselines.
-   **Inputs**: `artifacts/metrics.json`.
-   **Visuals**: Bar charts comparing Accuracy and Macro-F1 across Trivial, Simple, and AI baselines.
-   **Metrics**: False Auto-Handle Rate (the critical safety metric).

### 4. Failure Analysis
**Purpose**: Reviews specific cases where the system failed to provide a correct response or decision.
-   **Inputs**: `artifacts/failure_analysis.json`.
-   **Display**: Lists failure modes, representative examples, and the diagnostic reason for the failure.

### 5. Golden Set Review
**Purpose**: Provides a transparent view of the ground-truth dataset.
-   **Inputs**: `evaluation/golden_set.csv`.
-   **Display**: A searchable table of the annotated examples.

### 6. Golden Set Annotator
**Purpose**: Internal tool for humans to label raw conversations.
-   **Inputs**: `evaluation/annotation_queue.csv`, `config/intents.yaml`.
-   **Interaction**:
    -   Displays a customer message and the brand's historical response.
    -   Allows selection of Correct Intent, Escalation status, Severity, and Expected Response Points.
-   **Output**: Saves labels back to `evaluation/annotation_queue.csv`.

### 7. Human Judge
**Purpose**: Collects human scores for generated responses to validate the LLM Judge.
-   **Inputs**: `artifacts/evaluation_results.json`.
-   **Interaction**:
    -   Presents a generated response and the evidence used.
    -   Provides sliders (0-4) for 7 dimensions: Relevance, Correctness, Groundedness, Helpfulness, Tone, Safety, and Completeness.
-   **Output**: Saves scores to `evaluation/human_scores.csv`.

### 8. Decision Log
**Purpose**: Provides a permanent record of engineering trade-offs.
-   **Inputs**: `docs/DECISION_LOG.md`.
-   **Display**: Renders the Markdown log directly in the UI.
